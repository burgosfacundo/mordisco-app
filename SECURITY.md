# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in Mordisco, please do not report it through a public GitHub issue.

Instead, use GitHub's **Private Vulnerability Reporting** feature available in the Security section of this repository.

When reporting a vulnerability, please include, when possible:

- A clear description of the vulnerability
- Steps to reproduce the issue
- The affected component or endpoint
- The potential impact
- Any suggested mitigation or fix

Security reports will be reviewed as soon as possible.

## Supported Versions

Mordisco is currently maintained as a portfolio and academic project.

Security fixes are applied to the latest version available on the `main` branch.

## Security Features

This repository uses GitHub security features including:

- Secret Scanning
- Push Protection
- Dependabot Alerts
- Dependabot Security Updates
- CodeQL Code Scanning
- Private Vulnerability Reporting
- Branch protection through GitHub Rulesets
